Welcome to the first release of **Podzzz**! This version marks the transition from the original Podium.

While the interface and functionality remains unchanged for now, the codebase has been modernized to align with the latest platform standards. I hope there's no bugs that comes up because of it, feel free to report any unexpected issues you encounter.

### What's Changed
- **Rebranding**: Full transition from Podium to Podzzz.
- **Compatibility**: Support for restoring backups from the original Podium app (`.podiumdb`).
- **Modernization**: Updated all dependencies and migrated to the new package structure.
- **Cleanup**: General codebase cleanup and removal of obsolete components.

Next up, I'll be addressing open issues from Podium and tweaking the interface to be more expressive.
